# 角色设计板：先定下「她是谁」

先出一张设计板，后面所有动作图都以它为参考。这一步决定整套主题的辨识度，值得多抽几次。

## 模板

```
【通用规则】（见 00-通用规则.md）

一张 Q 版角色设计板：{角色名}。
- 人设：{一句话，如「清风输入法的拟人形象，温柔安静的长发少女」}
- 外形：{发型发色}、{瞳色}、{服饰：款式与主色}、{标志性配饰，如「发间一朵白花、两片叶子、浅蓝飘带」}
- 画风：{如「柔和水彩质感的二次元 Q 版」}，2 头身左右，头大身小。
- 构图：半身像（到胸口以下），正面略偏 3/4 角度，视线看向{左/右}侧。
- 附：{3–5 个表情小图：微笑、开心、疑惑、闭眼、惊讶}，同一画风。
- 配色提取：画面角落给出 5 个主色色块。
```

## 要点

- **视线方向**：候选窗的人物通常挂在窗体右上角、朝向光标（窗体左侧）。主题配置里有 `flip = "x"` 可以镜像，所以画的时候朝哪边都行——但**同一套图里必须统一**。
- **半身像**：人物底边会被窗体盖住一小截，所以底边平切、不要画腿或背景。
- **配色提取**：后面的窗体框架图、候选窗配色（`accent_text` 等）都从这 5 色里取，整套主题才协调。
- 选定一张满意的作为「基准图」，保存好，后面每一步都附上它。
