# 配色主题：让 AI 写出「换色」主题

只想换个强调色，不需要图片。`themes/01-color` 就是最小的例子（10 行）。

## 提示词模板（直接发给文字模型）

```
你是清风输入法（WindInput）主题的编写助手。请根据我给的主色，写一个换色主题的 theme.toml。

规则：
1. 继承内置基础主题：第一行写 base = "_qingfeng"，不要复制其它内容。
2. 只写 [meta] 和 [colors]；[colors] 只覆盖这 5 个键，其它一律不写：
   primary            主色，单个十六进制色
   accent_text        选中候选的文字色：{light = 比主色深一档, dark = 比主色浅一档}
   accent_soft        选中候选的底色：主色加透明度，{light = "#RRGGBB1A", dark = "#RRGGBB2E"}
   accent_menu        菜单高亮文字色：比 accent_text 的 light 再深一档；dark 与 accent_text 的 dark 相同
   tooltip_accent     气泡强调色：{light = 浅一档, dark = 浅一档}，两档相同
3. 建议亮色下 accent_text 在白底上对比度 ≥ 4.5，暗色下 accent_text 在深蓝灰底（#121826）上对比度 ≥ 4.5（内置的「清风·绿」亮色是 3.8，属于可接受的下限）。
4. [meta] 写 name（中文主题名）、version = "1.0"、author。
5. 输出一个完整 toml 代码块，不要解释。

我的主色：{#ec4899}
主题名：{樱粉}
```

## 校验

```sh
python tools/check_theme.py themes/你的主题
```

再放进输入法的主题目录看看：候选窗选中态、菜单高亮、气泡是否可读。需要调的就是这 5 个色值。
