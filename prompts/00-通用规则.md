# 通用规则：每条画图提示词都先带上它

这一页的内容是**所有**画图提示词的公共前缀。后面每个模板里的「【通用规则】」就指这里的整段，直接复制粘贴到最前面。

## 可复制的前缀

```
【通用规则】
- 输出 PNG，背景完全透明（真透明通道，不要白底、不要棋盘格、不要阴影底）。
- 角色/物体边缘干净，不要彩色描边残留、不要半透明雾气、不要边缘光晕。
- 画幅内留出足够边距：任何部分（头发、衣袖、特效）都不能被画布边缘裁断。
- 同一套图的画风、线条粗细、上色方式、光源方向、色调必须完全一致。
- 不要出现文字、水印、签名、logo。
- 不要多余的背景元素、地面、投影。
```

## 为什么要这些约束（来自实际踩过的坑）

| 现象 | 原因 | 对策 |
|---|---|---|
| 动画里人物头发、脸「抖」 | 每张图是独立生成的，头部位置和细节每次不同 | 用**同一张参考图**做图生图；固定种子；只让 AI 改要变的部位；见 [30](30-动作精灵图.md) |
| 人物半边被直线切掉 | 画布边缘裁断了身体 | 约束里写「不被画布边缘裁断」；底边需要被窗体盖住时，在配置里藏，不靠画图解决 |
| 边缘有黄红色碎边 | 抠背景留下的彩边 | 要求「真透明、边缘干净」；仍有残留时用 `tools/sprites_to_apng.py` 的 `alpha_low` 清理雾边 |
| 特效（星星、爱心）被切半 | 特效画到了格子边缘 | 在提示词里写明「特效距格子边缘至少 8% 边距」 |
| 换一批图后脸型、画风变了 | 不同批次生成存在漂移 | **同一个角色的所有状态用同一批/同一参考图**；要换风格就整套重做 |
| 每张图尺寸不一样 | 不同批次分辨率不同 | 精灵图脚本只认「每格方形 + 统一裁切框」；批次不同就分别配置 `crop` / `scale` |

## 数据底线

- 单个图片文件上限 16 MiB，整个主题包解压后上限 64 MiB。动画帧数多、画布大时先估算：`宽 × 高 × 4 × 帧数` 的量级会很大，PNG 压缩后通常是它的 1/4–1/2。
- 公开分发的素材要确认授权与署名：AI 生成的图请遵守所用工具的条款，署名或来源写进主题的 `[meta]` 或说明文件。
