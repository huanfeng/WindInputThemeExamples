# 提示词模板

用 AI 做出一套输入法主题，从易到难分四档。按需要选，不必走完。

| 想做什么 | 用哪些模板 | 要画图吗 | 对照示例 |
|---|---|---|---|
| 只换个强调色 | [40 配色主题](40-配色主题.md) | 不要 | `themes/01-color` |
| 静态皮肤（异形窗体＋不动的人物/挂件） | [10 设计板](10-角色设计板.md) → [20 框架图](20-窗体框架图.md) → [31 静态装饰](31-静态装饰图.md) → [50 皮肤配置](50-让AI写皮肤配置.md) | 要 | `themes/02-skin-static` |
| 动态皮肤（人物随输入动作） | 在上面基础上加 [30 动作精灵图](30-动作精灵图.md) | 要 | `themes/03-skin-animated` |

先读 [00 通用规则](00-通用规则.md)：每条画图提示词都要带上它，里面是踩过的坑。

## 用法

1. 模板里 `{…}` 是要你填的内容，花括号里的示例仅供参考。
2. 画图类模板需要支持「参考图/图生图」的工具；越能锁定角色，动画越稳。
3. 每做完一步都先校验、再往下：`python tools/check_theme.py themes/你的主题`。
4. 完整流程与打包发布见 [docs/workflow.md](../docs/workflow.md)。
