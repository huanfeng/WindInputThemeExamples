# 静态装饰图

只要一张不动的人物（或挂件、花枝、雪花……），比动画简单得多，也是「先上线再迭代」的好起点。

## 提示词模板

```
【通用规则】（见 00-通用规则.md）

参考图：{基准图，没有就写角色描述}。

一张{半身像 / 挂件 / 花枝}装饰图，用于挂在输入法候选窗的角落：
- 内容：{如「微笑的长发少女，半身像，视线看向左侧」}
- 构图：主体居中，底边平切（会被窗体盖住一小截）；四周留 5% 透明边距。
- 尺寸比例：{如 1:1}，分辨率不低于 {800×800}（显示时会缩小，素材大一些更清晰）。
```

## 接进主题

直接复制 `themes/02-skin-static` 改：把 `assets/mascot.png` 换成你的图，调整 `density`（越大显示越小）、`offset`（位置）、`flip`（镜像）。

- **想让它能被点击/拖动**：装饰缺省是 `hit = "drag"`（点中可拖窗口）；写 `hit = "block"` 只吞点击不拖动，`hit = "pass"` 则点击穿透到下面的程序。
- **不想占位置**：装饰不参与排版，伸出窗体多少都不影响候选。
