# 动作精灵图：让角色动起来

动态主题的人物动画由若干张「2×2 精灵图」合成。核心难点是**稳定性**：不同状态的图必须是「同一个人、同一个位置、同一个大小」，只有要动的部位变化。头发、脸一抖，动画就会显得很怪。

## 总原则

1. **一张精灵图 = 一个状态**，2×2 共 4 格，格子之间是同一个动作的不同阶段。
2. **必须带参考图**：把 [10](10-角色设计板.md) 选定的基准图（或上一张已满意的精灵图）一起交给 AI，让它「保持角色、构图、位置、大小完全不变，只改……」。
3. **固定种子**（支持的话）。同一批次之间脸型差异最小。
4. **每格是方形**，角色在格内的位置、大小一致；特效（爱心、问号、Zz）画在格子内，**离格子边缘至少 8% 边距**，否则会被切半。
5. 先做 idle 和 typing，满意后再做其他状态；换了批次/参考图后，已经做好的要重做，否则会有脸型跳变。

## 提示词模板（单张 2×2 精灵图）

```
【通用规则】（见 00-通用规则.md）

参考图：{基准图}。请保持角色、画风、发型、服饰、配色、头部位置、角色大小、构图与参考图完全一致。

生成一张 2×2 精灵图（四格，各格方形、尺寸相同，之间留空白），描述同一个角色连续的四个动作帧：
  格1（左上）：{帧1描述}
  格2（右上）：{帧2描述}
  格3（左下）：{帧3描述}
  格4（右下）：{帧4描述}

硬性要求：
- 四格里角色的头部、头发、肩膀位置和大小完全相同，只有{会动的部位，如「双手、眼睛」}不同。
- 角色底边与参考图一致（半身像，底边平切）。
- 特效距格子边缘至少 8%，不能被切断。
- 不要改变视线方向（始终看向{左/右}）。
```

## 状态与动作表（本仓示例用的这一套）

| 状态 | 用途 | 帧描述 | 精灵图在示例里的编号 |
|---|---|---|---|
| idle（眨眼） | 常驻 | 睁眼微笑；半闭眼；闭眼；半闭眼。头发、身体完全不动 | sheet-02 |
| typing | 打字中 | 双手在胸前的 4 种手势：并拢悬空、左手落下、右手落下、双手轻按。手势变化要小，别大幅度挥舞 | sheet-01 |
| happy | 上屏 | 微笑 → 张口大笑 → 双手合十＋爱心 → 淡去的爱心 | sheet-04 |
| poke | 被点击 | 正常 → 惊讶「！」＋动效线 → 闭眼「><」＋汗滴 → 恢复 | sheet-10 |
| think | 空码 | 一手托下巴，头顶问号，疑惑表情 | sheet-05 |
| sleep | 长时间无操作 | 趴在云上闭眼，头顶「Zz」逐渐变大 | sheet-06 |
| read | 翻页 | 戴圆框眼镜、手持书；翻页动作 | sheet-09 |
| cheer | 中英切换 | 握拳加油；比 V＋星星 | sheet-08 |
| glance | 停手片刻 | 眼睛看向一侧，头略转 | sheet-07 |

你不需要照抄这些状态，按你的角色设计动作。**最少只做 idle + typing 两个就能有「活」的感觉**。

## 合成动画

把精灵图放进 `sources/<你的主题>/sheets/`，复制 `sources/qingfeng-niang/sprites.toml` 改成你的：精灵图路径、每个状态的「图、格、毫秒」。运行：

```sh
python tools/sprites_to_apng.py sources/你的主题/sprites.toml -o themes/你的主题/assets/actions.png
```

脚本会打印每个状态的帧区间，贴进 `theme.toml` 的 `states`。节奏（眨眼停多久、打字每帧多长）全在 `sprites.toml` 里改，不用重画图。

## 常见问题

- **动画里脸在抖**：同一状态内 4 格的头部位置不一致 → 重新生成，带参考图并固定种子；实在不稳时，只保留头部稳定的格子，用少量帧循环。
- **打字帧循环不顺**：差异大的格子相邻会「跳」。把格子按「相邻差异最小」重新排序（例如 0→1→3→2），或只留差异小的几格。
- **切状态时脸型变了**：说明不同精灵图不是同一批次/同一参考。整套重做。
- **文件太大**：帧数、画布、`scale` 都影响体积；`scale` 调小或减少帧数；单文件不能超过 16 MiB。
