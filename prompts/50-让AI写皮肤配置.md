# 让 AI 起草皮肤配置（theme.toml 的 [skin]）

有了框架图和装饰图，剩下的是「几个数字」：拉伸带位置、内容框、装饰挂在哪。AI 可以起草，你再校验、微调。

## 先把事实量好，一起交给 AI

- 框架图：文件名、像素尺寸、面板外框坐标（左、上、右、下）、可拉伸的纯色区间（横向、纵向）。
- 装饰图：文件名、像素尺寸、希望显示成多大（逻辑像素宽高）。
- 位置：「挂在窗体的哪个角」「人物要不要朝向光标」。

## 提示词模板

```
你是清风输入法（WindInput）皮肤主题的配置助手。请为下面的素材写 theme.toml 里的 [skin] 部分，只输出 toml 代码块。

字段速查：
- [skin] density = N       图片 N 个像素 = 1 个逻辑像素（决定整体显示大小）。
- [skin.horizontal.frame]  image = "assets/xxx.png"；stretch_x / stretch_y = [{ from = a, to = b, fill = "stretch" }]
  图片像素。拉伸带必须落在「纯色/渐变」区，角落装饰在带外。
- [skin.horizontal.content] left/top/right/bottom = 文字区域距图四边的距离（图片像素）。
- [skin.horizontal.placement] caret = { anchor = "content.top_left", offset = [dx, dy] }；caret_above = {...} 窗体在光标上方时用。
- [[skin.horizontal.decor]]  装饰：image、density（本图密度，覆盖 [skin]）、anchor（挂在 frame 的哪个点，如 "frame.top_right"）、
  pivot（装饰自己的哪个点对到锚点，如 "bottom_right"）、offset = [dx, dy]（图片像素，y 为正向下）、
  z（<0 在窗体下，0–99 在窗体与文字之间，≥100 在文字之上）、flip = "x"（左右镜像）、hit = "drag"|"block"|"pass"。
- 竖排 skin.vertical.* 是与横排完全独立的一套，要单独写；不写则竖排不启用皮肤。
- 启用皮肤后窗体自己的背景/边框/阴影不生效，所以要把 [preedit_bar] 背景、[item.selected] 背景设为 "transparent"。

素材：
- 横排框架图 frame_h.png：{1320×408}，面板 {(24,48)-(1296,324)}，可拉伸区 横向 {300–840}、纵向 {150–260}。
- 竖排框架图 frame_v.png：{660×936}，面板 {(24,48)-(636,846)}，可拉伸区 横向 {180–330}、纵向 {180–640}。
- 装饰 mascot.png：{432×427}，希望显示约 {120×118} 逻辑像素，挂在窗体{右上}，朝向光标，底边被窗体盖住一小截。

要求：数字尽量从上面的素材推算，并在每行后用注释写出推算依据；不确定的地方写出来，不要编造。
```

## 校验与迭代

1. `python tools/check_theme.py themes/你的主题` ——查引用、帧区间越界、事件名拼写。
2. 放进输入法主题目录实际弹窗看：窗体拉开是否变形、人物位置、点击拖动是否正常。
3. 位置不对只改 `offset`，大小不对只改 `density`，拉伸变形说明拉伸带踩到了装饰。

## 动画装饰的事件配置

装饰是动图时，再追加 `states`（常驻状态与帧区间）和 `on`（事件触发的动作）。写法见 `themes/03-skin-animated/theme.toml` 头部的注释和文档站的「皮肤主题」页。给 AI 的提示词里把脚本打印的帧区间贴进去，再列出「事件 → 想要的动作」即可，例如：

```
状态帧区间：idle 0-3，typing 4-7，happy 8-14，poke 15-20（来自 tools/sprites_to_apng.py 的输出）
事件需求：打字 → typing；停手 3 秒 → idle；上屏 → 播一遍 happy 后回 idle；点击 → 随机播 poke 或 happy，播放期间不被打断
```
